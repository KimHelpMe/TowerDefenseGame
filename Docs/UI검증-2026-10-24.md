# 판타지 UI 적용 검증 (2026-10-24)

## 적용
- 기존 타워 아이콘을 유지하고 상단 자원/라운드, 좌측 시너지, 우측 본진/타워 정보, 하단 배치/스킬 영역으로 WBP 재구성.
- 시너지 툴팁: 모든 단계 조건과 효과 수치, 현재 보유 수, 기여 타워와 레벨 표시.
- 소환 카드: 실제 데이터 테이블의 공격/버프 정보, 대상/범위/지속시간/재사용 시간 표시.
- 타워 상세: 공격/지원 유형별 수치, 적용 효과, 강화 비용 표시. 공격 간격은 초 단위, 초당 공격 횟수는 간격의 역수로 표시.
- 결과 WBP: 도달 라운드/배치 수/전투 시간, 다시 시작/메인 화면 연결.

## 확인 결과
- TowerDefenseEditor Win64 Development 최종 C++ 빌드 성공.
- 메인 메뉴 포함 변경 UI WBP 13개 컴파일 및 저장 성공.
- 실제 마우스 배치 → 소환 카드 → 타워 선택 → 상세창/범위 표시 확인.
- 공격 타워 어둠병사: 공격력 52, 사거리 1700 및 공격 대상 정보 확인.
- 액티브 기계 지원포: 소환 카드와 상세창 범위 2150 일치 확인.
- 지속 버프 결빙의 현자: 범위 2050, 사거리 보너스 +120 표시 확인.
- 강화 클릭 후 골드 1000→800, 레벨 1→2, 버프 범위 2050→2100, 보너스 +120→+165, 다음 비용 400 G 갱신 확인.
- 시너지 툴팁에서 혼돈 2/4단계 수치와 기여 타워 어둠병사 Lv.1 확인. 스크롤 영역 밖으로 행이 넘치지 않음 확인.
- 게임 오버 결과 표시 및 메인 화면 복귀 확인. 이전 검증에서 다시 시작 시 자원/슬롯 초기화 확인.
- 일반 시작에서 전장 카메라 초기화 확인.

## 검증 범위와 남은 항목
- 에디터 PIE 검증이며 패키징된 실행 파일 검증은 하지 않음.
- 대표 공격/지속 버프/액티브 버프 타워를 검증했으며 전체 타워 조합의 전투 밸런스 검증은 포함하지 않음.
- 기존 데이터의 영문 이름과 설명은 유지. HTML 예시의 가상 수치 대신 실제 테이블 수치를 사용.
- 기존 시작 설정 경고(GameFeatureData AssetManager 항목, 폐기된 r.Mobile.VirtualTextures 설정)는 별도 정리가 필요함.

## 시너지 스택 수 정렬 추가 검증
- 현재 스택 수 내림차순 정렬. 동점은 데이터 테이블 순서로 고정.
- PIE 실제 SynergyList 자식 순서를 조회한 결과:
  - 화염 5 / 물 2: Fire, Water, Wind, Earth.
  - 화염 2 / 물 6: Water, Fire, Wind, Earth.
  - 화염 4 / 물 4: Fire, Water, Wind, Earth.
  - 반복 갱신에서도 동일 순서 유지. 스크롤 오프셋 80 유지 확인.
- C++ 빌드 성공, 실행 검증 로그 SYNERGY_SORT_PASS 확인.
