# Content 및 외부 에셋 복원 안내

## 공개 소스와 전체 프로젝트

공개 저장소에는 게임플레이 C++ 소스, 설정, `.uproject`와 이 안내를 포함합니다.
기존 로컬 프로젝트의 `Content/`는 약 1.65GB이며, 직접 만든 콘텐츠와 외부 에셋 팩이 함께 있습니다.
외부 에셋의 원본 재배포를 피하기 위해 이번 공개본에서는 `Content/` 전체를 제외했습니다.

따라서 공개본만으로는 맵·Blueprint·UI·DataTable이 복원되지 않습니다.
소스 확인과 기술 설명을 위한 포트폴리오용 저장소입니다.

## 전체 프로젝트 복원

### 기존 개발자의 로컬 보관본이 있는 경우

1. Unreal Editor를 닫습니다.
2. 보관한 프로젝트와 동일한 엔진 버전인 Unreal Engine 5.3을 준비합니다.
3. 전체 로컬 보관본의 `Content/`를 대상 프로젝트 루트 아래에 원래 구조 그대로 복사합니다.
4. 설정과 소스도 같은 보관 시점의 파일인지 확인합니다.
5. Visual Studio 프로젝트 파일을 생성하고 `Development Editor` / `Win64` 대상으로 빌드합니다.
6. Unreal Editor에서 프로젝트와 기본 맵을 열고 누락된 참조가 없는지 확인합니다.

이 저장소 업로드 작업에서는 실제 엔진 빌드와 플레이 검증을 수행하지 않았습니다.

### 외부 에셋을 새로 획득하는 경우

원래 개발자의 에셋 라이브러리 또는 구매 기록에서 정확한 상품·제작자·버전을 확인하고, 해당 배포처에서 각자 적법하게 획득해야 합니다.
공개 저장소만으로 정확한 상품 ID와 라이선스 이력을 확정할 수 없어 추측한 상품 링크를 넣지 않았습니다.

단순히 같은 이름의 팩을 받는 것만으로는 프로젝트 전용 Blueprint·UI·DataTable까지 복원되지 않습니다.
전체 보관본 또는 별도로 정리한 자체 콘텐츠도 함께 필요합니다.

## 이후 자체 콘텐츠를 공개할 때

1. 직접 만든 Blueprint·UI·DataTable과 가져온 원본 에셋을 구분합니다.
2. Blueprint 등의 외부 참조를 확인합니다. 원본 텍스처·메시·폰트를 함께 포함하는지 점검합니다.
3. 공개할 개별 경로를 확인한 뒤 `.gitignore`의 `Content` 제외 규칙을 세분화합니다.
4. 공개 가능한 `.uasset`·`.umap`은 Git LFS 규칙이 적용되는지 확인하고 커밋합니다.
