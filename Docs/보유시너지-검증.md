# 보유 시너지 목록 검증 (2026-10-24)

## 변경

- 보유 타워가 기여해 현재 스택이 1 이상인 시너지만 표시.
- 시너지 활성화 기준에 도달하지 않았더라도 보유 스택이 있으면 표시.
- 0스택 항목은 생성하지 않으며, 기존 항목이 0스택이 되면 Collapsed 처리.
- 스택 수 내림차순 및 동률일 때 데이터 테이블 순서 유지.

## 검증

- UE 5.8 TowerDefenseEditor Win64 Development 전체 빌드 성공.
- PIE 시작 후 타워가 없으면 시너지 항목이 없는 것을 화면으로 확인.
- 가챠에서 파도병사 선택 후 Water·Warrior·Human만 각 1스택으로 표시 확인.
- UnregisterTower 호출로 마지막 기여 타워를 집계에서 제거하면 표시 항목 0개: 통과.
- RegisterTower로 복구하면 같은 3개 항목 표시: 통과.
- 런타임 집계 값을 1·2·3으로 바꿔 Human 3, Warrior 2, Water 1 순서 확인: 통과.
- 검증 후 UpdateSynergies로 실제 보유 타워 기준 집계 복구.
- 가챠의 Unique·Common·Upgrade 색상 구분 및 설명 패널 표시 재확인.
- 슬롯 배치/가챠 클릭 및 마우스 오른쪽 가장자리 카메라 이동 재확인.

검사 로그: SYNERGY_OWNED_ONLY_PASS, SYNERGY_REMOVED_PASS, SYNERGY_RESTORED_PASS, SYNERGY_SORT_PASS.
