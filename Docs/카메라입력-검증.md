# 마우스 카메라 입력 복구 검증 (2026-10-24)

- 화면 가장자리에서 마우스로 카메라 이동. WASD 이동 바인딩 제거.
- 메인 메뉴 시작 후 GameAndUI 입력 모드에서 캡처 중 커서를 숨기지 않음.
- OS 커서 대신 기존 WBP_Cursor를 유지하도록 CurrentMouseCursor=None 설정.
- 컨트롤러 BP Tick의 강제 bShowMouseCursor=false 설정 제거.
- PIE에서 좌우 가장자리 이동, 중앙 정지, D 입력 시 위치 유지 확인.
- 수정 후 슬롯 설치와 슬롯 클릭으로 가챠 창 열림 확인.
- UE 5.8 TowerDefenseEditor Win64 Development 빌드 성공.
