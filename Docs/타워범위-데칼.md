# 타워 선택 범위 데칼

- 타워 블루프린트의 Components에서 상속된 `TowerRangeDecal`을 선택합니다.
- `Tower Range > Appearance > Range Color`로 색상, `Opacity`로 불투명도를 지정합니다.
- 실행 중에는 `SetRangeColor`, `SetRangeOpacity`를 호출할 수 있습니다.
- 텍스처: `/Game/03_UI/Art/T_RangeOutline`
- 머티리얼: `/Game/05_Materials/M_TowerRangeOutline`
- 원본: `Resources/UI/RangeOutline.png`, `RangeOutline.svg`

## 검증 (2026-10-24)

- UE 5.8 TowerDefenseEditor Win64 Development 빌드 성공.
- PIE에서 화염검사 선택 시 투명한 내부와 선명한 원형 외곽선 표시 확인.
- 실제 반경 1700에 대한 데칼 크기 보정 검증 통과.
- 실행 중 RangeColor 변경 및 Opacity 0.6 적용 검증 통과.
- 같은 타워를 다시 클릭하면 정보창과 범위가 함께 숨겨짐을 확인.
