# 가챠 카드 UI 검증 (2026-10-24)

- 기존 등급색 유지: Common 초록, Rare 파랑, Unique 빨강, Epic 금색, Upgrade 회색.
- 공통 테마 적용 뒤 등급명·테두리·상단 배지 색상을 적용해 색상 덮어쓰기 방지.
- 카드 설명을 기본 능력치, 지속/액티브 효과, 타워 특성, 강화 효과로 구분.
- 능력치의 항목명과 수치를 좌우 정렬. 숫자와 단위의 자동 줄바꿈 방지.
- 긴 설명은 카드 내부에서 스크롤. 아이콘 영역 보존.
- 카드 높이와 제목·버튼 간격 조정. 재추첨·포기 버튼이 화면 안에 표시됨.
- 카드 생성·재추첨 직후 색상 및 설명을 즉시 갱신.

## 검증 결과

- UE 5.8 TowerDefenseEditor Win64 Development 빌드 성공.
- 실제 PIE에서 서로 다른 등급의 테두리·텍스트 색상과 설명 구분 확인.
- 런타임 재추첨 검사: Common, Rare, Unique, Upgrade의 RGB 값과 3개 카드의 설명 패널 표시 검증 통과.
- 현재 맵의 풀에서 Epic은 뽑히지 않아 Epic의 실제 카드 표시 검증은 하지 못함.
- 슬롯 설치 및 가챠 창 열기, 재추첨·포기 버튼의 화면 내 배치 확인.
